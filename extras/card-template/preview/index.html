QUESTION · 回顾

为什么在 React 中不应该直接修改 state？

ANSWER · 答案

直接修改会保留原来的对象引用，React 可能无法判断状态已经改变，因此不会按预期重新渲染。

  • 破坏以引用比较为基础的更新检测
  • 让历史状态、调试和并发渲染变得不可靠
  • 应创建新值，例如 setItems([...items, nextItem])
核心不是“语法不允许”，而是保持状态变化可追踪、可比较。
