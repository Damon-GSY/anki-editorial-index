# Third-party notices

Editorial Index includes a compact, hex-only snapshot of the Catppuccin
palette for optional color themes. The snapshot contains all 26 official
tokens for Latte, Frappé, Macchiato, and Mocha; the first 14 tokens are
available as selectable accents.

- Project: Catppuccin Palette
- Source: https://github.com/catppuccin/palette/blob/v1.8.0/palette.json
- Version: 1.8.0
- Commit: `07d02aa110ef9eb7e7427afca5c73ba9cf7f8ebd`
- License: MIT; see `CATPPUCCIN_LICENSE` and
  https://github.com/catppuccin/palette/blob/v1.8.0/LICENSE

Catppuccin palette names and hexadecimal values are preserved as factual
source tokens. Editorial Index's semantic role mapping, accessibility
derivatives, menu integration, and Anki implementation are independent work.
The snapshot is bundled locally and is never fetched at runtime. Editorial
Index is not an official Catppuccin port and does not imply endorsement by the
Catppuccin project.
