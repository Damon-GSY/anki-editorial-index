# Bundled fonts

This directory contains Latin-focused WOFF2 subsets and native Inter TTF faces
generated or copied from locally installed versions of these open-source fonts:

- **Inter Regular / SemiBold** — Copyright 2020 The Inter Project Authors
  (<https://github.com/rsms/inter>)
- **Source Serif Pro Regular / SemiBold** — Copyright 2014–2019 Adobe Systems
  Incorporated, with Reserved Font Name “Source”

Both font families are licensed under the SIL Open Font License, Version 1.1.
The full license text is included in `OFL.txt`.

The WOFF2 subsets cover Latin, Latin Extended, punctuation, currency, arrows
and common symbol ranges. They serve Anki's embedded web views. The Inter TTF
faces register the same operational family for Qt-owned menus and controls.
Chinese, Japanese and Korean glyphs intentionally use the operating system's
native CJK font fallback.
