# 复习底栏间距与配色调整

状态：GPT-5.6 Sol 已完成首版本地实现与下述验证，等待用户确认效果。未安装或发布。

## 目标与范围

把 Cabinet 复习底栏改为尺寸克制、计数清晰、问答切换稳定的操作栏。只调整底栏的布局、字号层次和颜色，不重做首页、编辑器、卡片正文或调色板，不改变复习行为。

## 已查明的原因

- 本机 Anki 的 `aqt/reviewer.py::_showAnswerButton()` 把 `.stattxt` 计数放在 `#ansbut` 内；原生 `reviewer-bottom.css` 用绝对定位把它显示在按钮上方。
- `addon/web/cabinet.css` 的 `#ansbut .stattxt` 与其后代强制继承按钮文字颜色，但未清除原生定位。实心强调色按钮的浅色文字于是落到了浅背景上。
- 原生按钮有 9px margin，`theme.css` 的 `#outer` 有块向 padding，Cabinet 又给 body 和按钮加了 padding。需要统一空间归属，不能只再覆盖一个数值。
- `#ansbut` 当前使用 `--cb-accent` 全面积填充，当前紫色选择显得过重。颜色应保持用户选择，但调整在控件上的使用方式。
- `cabinet.fit_toolbars()` 在复习状态只显示 bottomWeb，不主动重新计算其高度。先确认 CSS 修正后是否仍有原生容器高度问题，不预先改高度机制。

以上是当前仓库与本机 Anki 源码证据；截图精确尺寸及用户运行中的插件版本仍需用隔离原生窗口复现，不能把截图像素直接当作 CSS 像素。

## 设计决定

### 空间与层次

- 用一层容器负责外侧留白，桌面目标上下约 16px、左右 24px；窄窗口可收至 12px。把底栏范围内的重复 padding、按钮默认 margin 明确归零。
- 显示答案按钮目标高度 48–52 CSS px，水平 padding 24px，10px 圆角，轻阴影。宽度大致 240–320px，但必须适应中间可用空间，不把最小宽度强塞进窄窗口。
- 计数在视觉上独立位于主按钮上方，间距约 8px、字号 12–13px、正常字重，等宽数字。保留原生内容和当前队列标识；计数关闭时不留下空白占位。
- 优先保留原生 DOM，靠有明确空间预留的 CSS 实现。仅在真实布局无法满足时才做最小标记调整，不引入 DOM 观察框架、重复文本或新的按钮包装系统。
- 编辑与更多保持低调的文字按钮、至少 40px 点击高度，和主按钮的可见按钮区域中心对齐，不能只对齐包含计数的整个中间单元格。
- 评分态沿用现有 2/3/4 按钮的语义、标题和间隔层次。统一外侧留白与按钮间隙，避免问答切换明显跳高、焦点被裁切。允许评分双行内容的必要高度，不把所有状态强塞进固定高度。
- 保留本机原生窄窗口行为，不借此次任务重做侧边操作的断点策略。

### 配色

- 底栏保持主题中性色背景与细分隔线。
- 主按钮改为淡强调色底、可读的强调色文字和细边框；首选复用现有 `--mist-accent-soft`、`--mist-accent`、`--mist-focus` 等语义 token，按实际对比度决定组合，不直接硬编码紫色或改官方色值。
- 常态不使用大面积高饱和填充；hover/pressed 稍增强底色和边框，focus-visible 清晰但不产生厚重双描边。
- 独立计数使用主题次级文字颜色，避免从 on-accent 继承。若保留原生各队列颜色，须确保每段在实际底栏背景上可读；保持当前队列下划线等非颜色标识。
- 重来、困难、良好、简单继续使用自己的评分语义色，不随所选强调色变成同一颜色。
- 四个 Catppuccin flavor × 14 accent 均应可读，暖纸与暗色暖纸保留。目标普通文字对比度至少 4.5:1，焦点与边界按实际背景判断。

配色依据为 [Catppuccin 官方样式指南](https://github.com/catppuccin/catppuccin/blob/main/docs/style-guide.md) 的背景、正文与标签角色，以及现有项目的可读性派生 token。这里只调整底栏消费方式，不重构颜色系统。

## 实施顺序与文件归属

1. 在现有原生实验环境中确认问题状态，记录当前尺寸与计数位置。重点覆盖 Latte + Mauve、计数开启的提问态。
2. 主要修改 `addon/web/cabinet.css` 中 `reviewer-bottom` 规则，统一外层空间、主按钮和计数样式。尽量不改 `theme.css`，防止影响经典布局；若必须修改共享规则，要保持经典模式行为。
3. 只有观察到实际高度裁切或切换遗留空白时，才在 `addon/cabinet.py` 或已有相关注入路径调整一次合适的原生高度更新，不增加轮询或任意延时循环。
4. 扩展现有复习底栏测试/原生实验入口，加入这次真实漏测的提问计数场景。评分验证已有覆盖可复用，不重写完整测试框架。
5. 生成本地问答对比截图与简短结果记录，交回主任务审阅；不部署。

允许修改的范围：上述底栏样式、必要的既有底栏高度代码，以及 `design-exploration/production-preview/` 或 `design-exploration/anki-cabinet-lab/` 中直接相关测试。可把本次证据放到 `local-tests/reviewer-footer-2026-09-19/`。不编辑早期设计探索、小红书/公众号素材或其他未跟踪文件。

## 验证与完成标准

每项检查须回答它能发现什么问题、失败后改哪里；已通过且未受新修改影响的结果不重复跑。

- **提问计数与几何**：检查计数不压按钮、不碰分隔线、未继承浅底白字；外侧留白与按钮高度符合设计。覆盖计数开启/关闭以及真实支持的计时器状态。失败则修局部布局或文字颜色。
- **配色**：用现有 token 与实际渲染背景自动核对四 flavor × 14 accent 的主按钮、计数及交互态文字；包含暖纸。失败只修底栏 token 组合或确有问题的派生值，不新增手写调色板。
- **原生回归**：在独立测试资料库中检查提问→显示答案→评分→下一张与撤销，确认原生命令、快捷键和卡片内容保持。看当前本机 Anki/Qt 版本下 820px 与 1280px 窗口，补一次正常可用的 UI 缩放；真实窗口出现裁切才处理高度代码。
- **问答对比图**：至少给出 Latte + Mauve 的问答底栏、Mocha 对照与一个窄窗口。图来自实际 Anki 控件，不重画 UI，不读取日常资料库。
- **现有项目检查**：运行受影响的测试；如改共享样式或注入路径，运行 `npm run test:ui` 和相应 Python 测试。只改 Cabinet 专属规则时不为数量重跑无关编辑器/分享素材验证。
- **最终交付**：修改文件、确实运行的检查、截图路径与必要限制。正确的部分直接说明正确，不制造问题；不新增 hash/checksum、功能开关、兼容框架或重复审核轮次。

## 本轮实施记录

生产改动仅在 `addon/web/cabinet.css` 的复习底栏规则。主按钮实测高度 50px，计数与按钮间距 8px，提问态和评分态两侧操作中心偏差均为 0px。计数关闭后收回占位；评分语义及原生命令保持。没有修改原生高度机制、全局色板或卡片正文。

常态使用 soft accent 表面。审阅时发现加深 hover/pressed 填充会令部分组合对比度不足，已改为保持可读表面，通过边框与阴影反馈状态。

实际完成的验证：

- `python3 design-exploration/anki-cabinet-lab/run.py --production --footer` 通过，23 项定向检查；包括本机 Anki 26.05b1 下 Latte/Mauve 1280px、820px、Mocha、计数开关、提问到答案、原生 ans/ease 命令以及侧按钮对齐。
- 原生调色板预览的四 flavor × 14 accent 常态文字对比度检查通过。Latte/Mauve 按钮 4.77:1、计数 5.53:1；Mocha/Mauve 分别为 6.59:1、9.26:1。
- `python3 scripts/test_catppuccin_palette.py` 通过；新增与 CSS 规则绑定的 56 组 hover/pressed 对比度验证。交互态修正不影响常态截图，没有重复运行长原生流程。
- 新增实验入口 `--production --footer`，可在生成的测试资料库复现本次检查。
