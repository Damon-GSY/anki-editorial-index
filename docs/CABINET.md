# 卡匣布局：开发预览版

卡匣已从浏览器原型迁入同一个 `mistline_ui` 插件；不是另装一个会叠加样式的插件。当前代码和预览包位于 `codex/cabinet-local-migration` 分支，尚未合并到 main 或发布到 GitHub Releases。

## 使用

1. [下载预览包](https://github.com/Damon-GSY/anki-editorial-index/raw/refs/heads/codex/cabinet-local-migration/dist/Editorial-Index-Cabinet-preview.ankiaddon)，在 Anki「工具 → 插件 → 从文件安装」中选中它，安装后正常重启。详细步骤见 [安装指南](./INSTALLATION.md)。
2. 打开「工具 → Editorial Index 布局 → 卡匣 Cabinet」。
3. 原来的「Editorial Index 配色…」和「快速配色」继续使用；布局与 Catppuccin flavor / accent 分开选择。

首页右上角也有「配色」按钮，显示当前主题名称与强调色色样。点开调色板后，选择四种 Catppuccin 主题之一，再点选 14 种强调色；选择立即应用并保存在本机，不需要额外保存。自动模式继续跟随 Anki 日／夜模式，暖纸主题也保留。

「界面预览」直接加载当前布局的实际插件样式，展示标题、主按钮和评分栏；其中内容与复习间隔只是示例，预览按钮不会进行学习或评分。强调色不会覆盖重来／困难／良好／简单各自的语义色。「颜色用途与色值」页签保留详细色值。小窗口可滚动选择区，预览和关闭按钮保持可见。

调色板使用等宽、等高的选择按钮，选中或键盘聚焦时不改变位置。按钮行距与标签间距为 8px，主题／强调色分组间距为 20px；预览内容共用左右对齐线与 16px 内边距。首页按钮已清除 Anki 原生外边距，避免与布局间距叠加。

配置对应 `layout: "cabinet"`。旧配置或新安装的默认仍为 `editorial`，不强制改变其他用户的布局。换回「经典 Editorial」即可恢复旧布局，关闭「Editorial Index 主题」则回退 Anki 原生界面。

## 首页展示与收起

首页的「展示设置」或「工具 → Editorial Index 首页展示…」可以管理当前账户的顶层卡匣：

- **首页显示**：默认勾选。取消后隐藏整只卡匣及其中的子牌组；不删除牌组、不暂停卡片、不改变复习安排。
- **收起内容**：默认不勾选。收起后仍保留卡匣名称、计数和打开入口。
- 设置窗口支持按名称搜索；搜索只筛选设置列表，不改变任何勾选状态。点击「保存」应用，「取消」放弃本次修改。

卡匣右上角也可直接收起／展开；首页「全部收起／全部展开」只影响当前可见卡匣，保留隐藏卡匣原有的折叠状态。设置按 Anki 账户分别保存在本机插件配置中，重启后仍保留；新建顶层牌组默认显示并展开。

即使隐藏了全部卡匣，首页仍保留设置入口。「恢复默认（全部显示并展开）」后点击「保存」，即可重新显示所有卡匣。整个卡匣的收起与 Anki 原生的子牌组折叠是两种独立操作，不会相互改写。

## 保留的功能

- 真实牌组、每日限额计数和父子层级；子牌组折叠及每级牌组选项均由 Anki 处理。整个卡匣的显示／收起仅是插件展示偏好。
- Shift-click 选择牌组；点击「打开牌组」进入原生概览，再开始学习。
- 原生翻面、评分、输入答案比较、撤销、图片、公式和挖空模板。
- 底部评分使用柔和的主题语义色和分层字号；兼容用 `<font color>` 给评分文字上色的插件，不需要卸载它们。此兼容仅作用于卡匣评分栏，不修改卡片正文。
- 原有编辑／浏览／统计窗口样式和 Review Heatmap 配色。
- 正在复习时切换布局或配色，不重新加载卡片，也不清空已输入的答案。

## 已知边界

- 拖拽整理牌组层级暂时需要切回经典布局。
- 卡片正文保留模板的字体及 HTML。若模板文字与主题纸面不协调，优先改变纸面而不是改写模板；不能承诺任意第三方模板的每个自定义元素都适配。
- Add / Browse 等窗口保留原有美化，没有在这轮完整改成卡匣设计。
- 实机测试版本为 macOS 上的 Anki 26.05b1 / Qt 6.11.0；跨系统和其他版本仍需验收。读取不到受支持的牌组数据结构时保留原生牌组列表。

## 验证

`design-exploration/anki-cabinet-lab/run.py --production --verify` 会将正式插件复制到独立临时资料库，用生成的笔记运行实际 Anki 调度，不读取日常资料库。报告与截图写在 `production-evidence/`。

升级使用 Anki 的「从文件安装」，不要先卸载。需要额外备份时，可在退出 Anki 后备份插件目录（包含 `meta.json` 和 `user_files`），然后重新打开 Anki 安装。不要移动或替换学习资料库；手动修改过的插件源码应另行备份。
